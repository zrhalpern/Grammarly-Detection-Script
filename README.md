<h1>Grammarly Detection Script - Intune</h1>

<h2>Description</h2>
This read-only PowerShell script detects the presence of Grammarly (desktop installations or browser extensions) on Windows 11 systems by querying the Windows Registry and scanning currently logged-on user profiles.
<br />


<h2>Languages and Utilities Used</h2>

- <b>PowerShell</b> 
- <b>Intune</b>

<h2>Environments Used </h2>

- <b>Windows 11</b> (25H2)
